EDUCAM RAS - APK BUILD

This package contains the working Educam RAS web app plus a GitHub Actions workflow that automatically builds an Android debug APK.

Quick method:
1. Create a GitHub repository.
2. Upload ALL files/folders from this package (not the ZIP itself).
3. Make sure the default branch is named main.
4. Open the repository's Actions tab.
5. Run "Build Educam RAS APK" if it has not already started.
6. After the workflow finishes, open the run and download the artifact named "Educam-RAS-debug-apk".
7. Extract the artifact and install app-debug.apk on Android.

The app ID is com.educamras.app and the app name is Educam RAS.
